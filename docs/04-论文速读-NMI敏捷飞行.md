## 一句话

用**可微物理仿真**把损失梯度直接穿过物理模型反传，训练端到端视觉飞行策略，让多旋翼在**无通信、无建图、无里程计、只靠 21 美元单板机**的条件下，在森林中以 **20 m/s** 飞行，并能多机自组织穿越窄门。

---

## 1. 它要解决什么问题

| 路线 | 痛点 |
|---|---|
| **传统建图规划**（mapping → planning → control） | 级联结构带来延迟与误差累积；高速/动态环境失效；多机还要显式建体素图表示彼此 |
| **强化学习** | 样本量随机器人数量指数增长；把动力学当黑箱，只做零阶梯度估计 |
| **模仿学习** | 依赖专家演示；集群专家策略极难设计；稠密障碍+高速下标注质量差、趋向匀速飞 |

作者的切入点：**别把动力学当黑箱**。物理解析可微 → 能拿到一阶解析梯度，方差远低于零阶估计。

## 2. 方法关键

### 2.1 优化框架

```
min_θ  L(θ) = Σ_k l(x_k, π_θ(o_k))
```

梯度沿动力学雅可比链式回传：

```
∂L/∂θ = (1/N) Σ_k [ Σ_i (∂l_k/∂x_k) · Π_j (∂x_j/∂x_{j-1}) · (∂x_i/∂θ) + (∂l_k/∂u_k)(∂u_k/∂θ) ]
```

### 2.2 故意用极简质点模型（反常识）

只积分加速度与速度：

```
v_{k+1} = v_k + a_k·Δt + ½(a_k+1 − a_k)Δt
p_{k+1} = p_k + v_k·Δt + ½ a_k Δt²
```

再用「固定延迟 τ + 指数平滑 λ」的一阶低通模拟飞控响应，加**二次空气阻力**。
`τ`、`λ`、阻力系数通过标定匹配真实平台。

> 与"必须高保真才能 sim-to-real"的常识相反，但换来**更快的梯度计算**和**更平滑的优化地形**。
> 消融显示：质点模型 > CTBR > 完整刚体（收敛速度与最终性能都更好）。

### 2.3 时间梯度衰减（本方法的关键工程技巧）

直接 BPTT 会**梯度爆炸**（远处障碍的梯度累积过大）。解：

```
∂x_j/∂x_{j−1}  →  (∂x_j/∂x_{j−1}) · e^{−αΔt}
```

两个作用：
1. 抑制梯度累积；
2. 让监督信号只来自**近未来**——符合传感器感知范围有限这一物理事实。

消融：α ∈ [0.25, 4] 都明显优于原始 BPTT，且对具体取值不敏感。

### 2.4 物理驱动的损失（4 项加权）

| 项 | 形式 | 作用 |
|---|---|---|
| 速度跟踪 `L_v` | 对 2 s 滑动平均速度用 **Smooth L1** | 局部专心避障，长程再跟速 |
| 避障 `L_c` | `接近速度 × [截断二次项 + softplus 势垒]`，β₁=2.5、β₂=32 | 可微的 barrier function |
| 加速度 `L_a` | ‖a_k‖² | 动态可行性 |
| 加加速度 `L_j` | ‖(a_k − a_{k+1})/Δt‖² | 平滑 |

权重：λ_v=1, λ_c=2, λ_a=0.01, λ_j=0.001

### 2.5 网络与观测

```
深度图（取反 → max-pool 16×12）
   → Conv 32(2) → 64(3) → 128(3)  [每层 leaky ReLU]
   → flatten → 192 维
                                    ┐
姿态估计 / 目标速度 / 速度估计(可选) ┘ → 投影到 192 维 → 逐元素相加
   → GRU（隐藏状态替代显式里程计）
   → FC → 期望推力加速度（+ 速度估计）
```

机体**偏航始终对准目标方向**，以此唯一确定姿态。

### 2.6 训练环境（极简但有讲究）

- PyTorch + 自写 CUDA 扩展，每批 **64 个并行环境 × 150 步**，Δt = 1/15 s
- 场景只有 4 类基本几何体：平面、长方体、球、圆柱（随机尺寸/位置）
- **不用高保真渲染器**，但泛化到真实森林

## 3. 三个主要实验

### 3.1 复杂/动态环境高速飞行

- 自研 FPV 机：**365 g**，RealSense D435i（15 Hz 深度），Mango Pi（$21，4×A53 1.5 GHz + 1 GB RAM）
- 场景：密林、城市公园、脚手架、废弃工厂，**全部零样本迁移**
- 森林峰值 **20 m/s**（此前模仿学习方案的两倍）
- 关门 / 平移障碍 / 摆环等动态障碍下，7 m/s **10/10 成功**
- 靠 GRU 的单帧输入隐式感知运动

### 3.2 无通信蜂群导航

- 6 机分两组**对穿窄门换位**；8 机并行飞行
- 每机只拿本体坐标系下的**自身速度 + 目标方向**，不共享任何信息
- 涌现行为：**等待、跟随、退让让行**（未经显式设计）
- 对比 Ego v.2（需通信 + 全局定位）：成功率相当
  - 换位：4.7 s vs 4.0 s（我们慢，因谨慎横移）
  - 并行：**6.5 s vs 9.0 s**（我们快）
- 同环境 PPO 基线：成功率仅 30–70%（并行）/ 10–30%（换位），**且不出现群体行为**

### 3.3 无里程计飞行

- 训练时不喂位置/速度，仅姿态 + 深度
- 成功率与用 Vicon 真值的版本**持平（100%）**
- 对比 Vins-Fusion 版：7 m/s → 90%，10 m/s → 80%
- 额外监督预测速度：最高 7.74 m/s 的飞行中平均误差 **0.78 m/s**
- Grad-CAM：激活集中在**直接构成碰撞威胁**的障碍上

### 3.4 对比与消融

- 1,000 次迭代达 **100% 成功率**（Agile 20%、PPO 30%）
- 达同奖励只需 **PPO 10% 的采样**
- 训练 0.8 h（GTX 1080）vs Agile 3.4/4.3 h
- 最终奖励 −5.63，优于 Deep-ILC 的 −7.46

## 4. 作者承认的局限

1. **视场角受限**：偏航锁定目标方向，长时需转向的场景受限；急加减速时相机朝地/朝天，感知失效；集群中视野外同伴可能相撞（补充视频 9 有记录）。
2. **质点模型**：做不了特技类机动，换刚体模型才有空间。
3. **气阻需逐平台标定**，无在线标定。
4. 集群实验依赖动捕提供目标方向与速度（实验设置上的"外援"）。

## 5. 评价

**真正的新意**不在"端到端视觉飞行"（Agile、Ego 系列已做过），而在于：

- 首次把**可微物理成功用于真实四旋翼视觉导航**；
- 证明"**物理先验 + 一阶梯度**"比零阶 RL 省一个数量级样本。

**最值得复用的两个工程点**（都是"反常识但有效"）：

1. **时间梯度衰减** —— 解决可微仿真的梯度爆炸，且物理意义清晰；
2. **故意降保真度的质点模型** —— 换取更好的优化地形。

**可质疑处**：

- 集群结论建立在动捕提供目标/速度、且"彼此建模为一个球"的简化上，真实无 GPS/无动捕野外集群未验证；
- 20 m/s 只在直通森林展示，成功率样本 10 次量级，统计偏薄；
- 与 Ego v.2 比较时，对方被剥夺了赖以工作的通信/定位优势，公平性需辩证看。
